# ПО «Поддержка составления расписания учебных занятий»

Программное обеспечение для автоматизации процесса составления и проверки расписания в учебном заведении.

## 🛠 Технологический стек
*   **Язык:** Python 3.10+
*   **Интерфейс:** PySide6
*   **СУБД:** PostgreSQL

## ✨ Ключевые возможности
*   Управление справочниками (группы, преподаватели, аудитории, предметы).
*   Составление расписания с защитой от накладок на уровне БД (один преподаватель/аудитория/группа не могут быть заняты дважды в одно время).
*   Продвинутая аналитика: поиск свободных аудиторий и преподавателей, расчет нагрузки, компактное расписание (STRING_AGG, CTE).

## 🚀 Установка и запуск
1. Разверните базу данных: создайте БД `laboratory_3_schedule` и выполните скрипт `schema.sql`.
